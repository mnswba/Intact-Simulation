Tutorial 1 · Create and verify your first part

Choose a small mechanical part whose dimensions you can check. Use this prompt:

Create an 80 mm diameter pipe flange, 8 mm thick, with a concentric 24 mm bore and six 6 mm through holes on a 60 mm bolt circle. Use millimeters. Save checkable requirements, verify the hole diameters and positions against native geometry, inspect the model and export STEP.
  1. Review any dimensional assumptions before building. Clarify critical interfaces.
  2. Open the returned model viewer. Drag to orbit, scroll to zoom and press F to fit the model.
  3. Use front, top and right views to inspect the bore, thickness and pattern. Turn on Grid if helpful.
  4. Ask: “Report the measured envelope, bore diameter, hole count and centers. List failed or unverified requirements.”
  5. Download STEP under Files & exports. Use the native export for CAD exchange and a mesh format for an appropriate visualization or printing workflow.
A successful build and a good-looking render are the start of review. Check dimensions, units and native features before using the file downstream.

Tutorial 2 · Select geometry and make a controlled edit

  1. Choose Parts, Faces or Edges in the Selection menu. Double-click selects a part; triple-click selects a native solid body. Use Ctrl/Cmd-click to add selections.
  2. For an edge, hover until the amber preview identifies the candidate. Press Tab or Shift+Tab to cycle nearby candidates. The pick radius can be adjusted in Settings → Edges & guides.
  3. Open Ask AI or press A. Choose a geometry change or a read-only question.
  4. Describe exactly what should change: “Increase these bolt holes from 6 to 8 mm. Keep the 60 mm bolt circle, bore and outer dimensions unchanged. Verify the changed holes.”
  5. Inspect the returned revision and verification evidence. Select again if the earlier face or edge reference has become stale.

Ask AI uses the supported ChatGPT message bridge when available. A standalone local viewer can instead start a scoped task through the signed-in local OpenAI client; progress and replies appear in Intact. That task does not post into whichever ChatGPT conversation happens to be open.

To ask a question without editing, choose Ask about geometry · read-only: “What is the native radius of this edge?” A reference drawing or annotation communicates intent; it does not engrave the model or create a constrained CAD sketch.

Constrained sketches and feature history

For a design that must preserve relationships, ask for a structured sketch with explicit constraints and a supported feature graph. Request remaining degrees of freedom and conflicts before building the feature. A drawing annotation is not a solved sketch. An imported STEP solid does not automatically acquire the original author’s parametric history.

TPMS and lattice geometry

Create a 24 mm gyroid sheet lattice with an 8 mm cell size. State the sampling resolution and representation. Check the exported mesh and report its sampled volume. Export STL and 3MF.

Inspect the interior with a section cut. A sampled gyroid is a mesh approximation. A separate faceted STEP conversion, where supported, does not recover an exact smooth surface. Ask for a millimeter distance-offset workflow when wall dimensions matter; a dimensionless sheet-band setting is not a guaranteed wall thickness.

Tutorial 4 · Prepare an engineering study

Open Simulation, then choose the study that fits the question.

Mechanical Analysis

Specify the solid or supported domain, material values, units, actual boundary selections and desired result. For structural work, give supports and loads; for thermal work, conductivity and thermal conditions. Ask AI prepares and runs a supported study when those inputs are sufficient.

For this single solid, prepare a small-strain linear-elastic compression study. Confirm the material, fixed face and total load before solving. Report displacement, stress, support reaction, mesh quality, residual, force balance and refinement status. Preserve the CAD revision.

Read the reported effective mesh resolution and convergence status, not just the color scale. A budget-limited refinement remains unverified. Whole-vehicle suspension/contact, nonlinear mechanics, turbulent/inertial CFD and multiphysics are outside the supported solver scope.

Virtual Analysis

Choose a vehicle, walking, translation, rotation or joint preview and identify the separate moving parts and pivots. Joint definitions use assembled CAD coordinates in meters. A fused solid cannot gain independent limbs simply by requesting an animation. Virtual Analysis is kinematic: it does not establish gravity, contact forces, traction, balance or physical performance.

Tutorial 5 · Export and share

Files & exports provides the formats supported by the current representation: native STEP, ASCII/binary STL, GLB, 3MF, project JSON, USD/USDA and available native documents. Native FreeCAD files depend on the structured workflow. Mesh-only assemblies do not have an exact native STEP equivalent.

Use Project for an annotated PNG, BOM CSV, multi-view PowerPoint or supported 2D DXF/DWG. PowerPoint captures a pinned revision headlessly and includes actual views, measured context and a complete component register. The drawing exports are sampled wireframe projections, not automatically dimensioned manufacturing drawings.

Create a review presentation of the current revision. Include measured dimensions, component names, audit status and unresolved design assumptions. Keep the live camera unchanged.

When something needs attention

  • Intact is missing in ChatGPT: finish local installation, restart the desktop client, enable the plugin and start a new conversation.
  • Runtime not ready: ask for status and follow the installation diagnostics. Do not bypass the CAD sandbox.
  • Ambiguous geometry: select the current part, face or edge and send a fresh request.
  • Audit failed: inspect the actual failed check and repair that feature. Retain the last accepted revision.
  • Unexpected analysis: check units, material, source revision and boundary selections before interpreting the result.
