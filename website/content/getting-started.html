First time here? Set up Intact once.

Your ChatGPT account supplies the AI conversation. Intact’s local plugin supplies the CAD tools, engineering runtime and model viewer. Opening ChatGPT does not automatically install Intact. The current release uses a personal local plugin installation rather than a public marketplace download.

  1. Check your computer. Use Linux x86-64, or Windows with Ubuntu/WSL2. The runtime requires Python 3.12–3.13, uv and working Linux namespaces/bubblewrap. Native Windows and macOS execution are not supported by this installer.
  2. Download the installation package. It contains the plugin files, runtime setup scripts and required notices. It is a ZIP package, not a standalone Windows installer. Extract it on the supported Linux/WSL host.
  3. Prepare the runtime and run setup. Use the commands below inside Linux or Ubuntu/WSL. The installer prepares pinned CAD dependencies and registers the personal plugin. Allow several GB of disk space; the FreeCAD download alone is approximately 0.8 GB.
  4. Restart and enable. Restart the ChatGPT desktop client, select Intact Simulation in your personal plugin marketplace and open a new conversation.
  5. Check and build. Ask ChatGPT to check Intact status, then try the dimensioned prompt below.

Linux / Ubuntu setup commands

Install uv using its official instructions. In a terminal inside the extracted Intact installation folder, run:

sudo apt-get update
sudo apt-get install -y build-essential bubblewrap libgl1 libglu1-mesa libxft2
python3 scripts/install-chatgpt-plugin.py

For the Windows ChatGPT desktop client, replace the last command with the following, still running inside WSL. Replace the profile name with your Windows user folder:

python3 scripts/install-chatgpt-plugin.py --windows-home /mnt/c/Users/YOUR_WINDOWS_USER

The installer’s default WSL distribution is Ubuntu-22.04. If yours differs, add --distro YOUR_DISTRO. CAD generation requires the isolated runtime; do not disable it to work around an installation error.

Your first conversation

Use Intact Simulation. Check that the CAD runtime is ready. Create an 80 mm diameter pipe flange, 8 mm thick, with a 24 mm bore and six 6 mm through holes on a 60 mm bolt circle. Save checkable requirements, verify the native geometry, show the viewer and export STEP.

Inspect the model, read the measurements and try a small geometry-aware edit. The How to Use tutorial covers selection, Ask AI, Review, simulation, exports and keyboard shortcuts.

CAD runs locally, while the selected request and relevant model context are sent to the AI provider through the client. Read Privacy & data before using confidential models.
