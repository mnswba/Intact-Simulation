Set up Intact on another computer

  1. Download the Windows ZIP. Save {{WINDOWS_FILENAME}} in the new computer’s Downloads folder. The current package supports Windows x86-64; it does not run natively on MacBook/macOS or in an ordinary web/mobile chat.
  2. Open Codex and sign in. Use a local Windows Codex host with access to that folder. Sign in using your own ChatGPT account with Codex access. Official Codex setup ↗
  3. Ask Codex to install the private plugin. Open a conversation with access to the downloaded file and paste the installation request below. Codex should register the package through a local marketplace while preserving your existing plugins.
  4. Restart, enable and wait for setup. Restart the desktop host, enable Intact Simulation in the local plugin source and start a new local conversation. First use downloads the CAD runtime and libraries. Allow internet access, several GB of free space and time to finish; later starts reuse the cache.
  5. Check the version and build. Ask Intact to check its status: version {{WINDOWS_VERSION}}, CAD ready, desktop setup ready and 65 tools. Open Tutorial in the viewer to confirm its version, then try the flange prompt below.

Your first model

Using Intact Simulation, create an 80 mm diameter flange, 8 mm thick, with a 24 mm bore and six 6 mm through holes on a 60 mm bolt circle. Verify the native dimensions and hole positions, export STEP and STL, and open the viewer.

Inspect the geometry and evidence rather than accepting a screenshot alone. The How to Use tutorial covers selection, Ask AI, Review, supported simulation, exports and shortcuts.

Move designs separately

The plugin ZIP contains no private models or sign-in profiles. Export designs as project JSON on the original computer, transfer the files and import them on the new computer. The original laptop does not need to remain connected. Each user’s computer runs its own CAD tools.
