Intact connects a conversational assistant to local CAD and numerical tools. You describe a part, inspect the result in a viewer and refine the design with explicit dimensions and selected geometry. The assistant interprets the request; open-source geometry and solver engines perform the supported computations on your computer.

Begin with dimensions and acceptance checks

A useful request includes units, the intended part or assembly, required features and the checks that would establish success. For example, specify a flange’s outside diameter, thickness, bore and hole pattern, then ask to verify the actual exported geometry. Missing dimensions that affect fit or function should become clarification questions.

The local workflow can create native solids, retain named parts and support structured sketches, parameters and feature operations. Imported STEP does not automatically recover its original parametric history. Geometry checks and available edit operations depend on the representation of the current model.

Inspect, select and revise

Select a part, face or edge, attach relevant references and describe the change. Ask AI saves the request and its model revision before starting work. When a supported ChatGPT component bridge is available, it can send a follow-up through that host. Otherwise, the localhost viewer starts a separate model-scoped task using the signed-in OpenAI local client. Progress and replies appear in Intact; this task does not join the open ChatGPT conversation.

Revision guards and reference checks help prevent an edit from targeting stale geometry. Ambiguous or invalid references require clarification or reselection. After rebuilding, verify the result and the requested exports against the updated requirements.

Run a bounded engineering study

Supported studies need physical inputs, units, materials and boundary conditions. Mechanical Ask AI can run the analysis once those inputs are sufficient. Review actual solver results, mesh quality, reactions and convergence evidence. Current structural analysis supports one native solid; whole-assembly contact and nonlinear mechanics are outside its scope. A rendered field is not engineering certification.

Browser demonstration and desktop execution

The interactive browser demo uses prebuilt examples to explain the experience. It does not run live AI generation, native CAD kernels or numerical solvers. Real computation requires the local plugin setup on Linux x86-64 or Windows with WSL2/Ubuntu. Native Windows and macOS execution are not currently supported.

The repository provides a local development plugin. Public ChatGPT directory approval has not been granted. Read the project documentation for installation, supported workflows and current limits.
