# Simulation

Use the current [current Ask AI workflow](ASK_AI_HANDOFF.md) and [v0.15 solver contracts](RELEASE_0_15.md).

Mechanical Analysis is driven by a description and one Ask AI button. Actual numerical solvers return fields and data; required physical inputs must be supplied or clarified. Virtual Analysis uses a model-bound kinematic driving/walking/machine preview and restores the viewer objects afterward. It does not predict dynamics or balance.

The older [v0.14 guide](SIMULATION_0_14.md) and [audit](SIMULATION_0_14_AUDIT.md) describe historical releases. Their manual simulation forms and PyBullet Virtual Analysis were replaced in v0.15.
