Read a source and pass it to `build_model` with the parameters in [`website/content/showcase.json`](../../website/content/showcase.json). All generated CAD must run through the Linux sandbox. Rebuild packages using the installed CAD-runtime Python:

```sh
python website/build-showcase.py --state-dir /tmp/intact-showcase-rebuild
```

Use a disposable state directory. Native STEP/mesh exports and geometry audits are generated; outputs are not committed. New packages include `design-prompt.txt` and `geometry-audit.json`. Display colors express material intent rather than assigned solver properties. These are inspectable geometry concepts, not manufactured, certified or physically validated products. Five older TPMS concepts are sampled meshes without exact smooth STEP.
